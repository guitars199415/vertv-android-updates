Open VerTv app Update VerTv Android app (required)

Phone pairing requires VerTv mobile 0.10.28 or newer. Older installed versions cannot open a TV code from this page. Update the existing app without uninstalling it, then scan a fresh QR code.

If the app does not open automatically: open VerTv manually, then My VerTv → Pair a TV. Enter the code above. Only approve a code you recognize. Codes expire after five minutes.
